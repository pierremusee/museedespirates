# MISSION D'INITIALISATION : FRONTEND MUSÉE DES PIRATES
**Destinataire :** Agent Devin / Agent UI
**Outil de persistance :** Mémoire Honcho

## 1. CONTEXTE GLOBAL
Le backend FastAPI (Port 8000) et la base de données PostgreSQL sont opérationnels. Nous devons maintenant créer l'interface client (réservation) et l'interface agent (scanner de QR code) pour le Musée des Pirates.
Le front-end doit être totalement isolé du backend dans son propre dossier.

## 2. STACK TECHNIQUE IMPOSÉE
- **Framework :** Next.js (App Router)
- **Langage :** JavaScript / TypeScript
- **Style :** Tailwind CSS + shadcn/ui (pour des composants rapides et propres)
- **Requêtes API :** Fetch natif ou Axios (pointant vers http://127.0.0.1:8000)

## 3. PLAN D'ACTION STRICT
Exécute ces étapes séquentiellement à la racine du projet global (à côté du dossier `backend`).

### Étape A : Création de l'application
1. Lance la création d'un projet Next.js nommé `frontend` avec la commande appropriée (utilise TypeScript, Tailwind, ESLint et le App Router).
2. Nettoie le fichier `app/page.tsx` généré par défaut pour y mettre un titre simple "Musée des Pirates - Billetterie" centré à l'écran.

### Étape B : Configuration de l'environnement
1. Dans le dossier `frontend`, crée un fichier `.env.local`.
2. Ajoute la variable : `NEXT_PUBLIC_API_URL=http://127.0.0.1:8000`.

### Étape C : Structure des routes
Crée la structure de dossiers suivante dans `frontend/app/` pour préparer nos futures pages :
- `(client)/` -> Groupe de routes pour les visiteurs
  - `reserver/` -> Dossier pour la page contenant le formulaire de réservation
  - `succes/` -> Dossier pour la page de confirmation affichant le(s) billet(s)
- `(admin)/` -> Groupe de routes pour le personnel du musée
  - `scanner/` -> Dossier pour la page dédiée au contrôle d'accès par QR code

### Étape D : Lancement et Test
1. Lance le serveur de développement Next.js.
2. Fais un rapport confirmant que le front-end tourne (généralement sur le port 3000) de manière indépendante du back-end, et mets à jour la mémoire Honcho avec cette nouvelle architecture.
